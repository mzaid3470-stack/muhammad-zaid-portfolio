PROJECT SCREENSHOTS DIRECTORY:
==============================
This directory stores verified project screenshots for your web development portfolio.

Current projects:
1. `excellent-coaching.png` - Live screenshot of "Excellent Coaching" (https://mzaid3470-stack.github.io/E-projectZaid/)
2. `vebra-sound.png` - Live screenshot of "Vebra Sound" (https://vebraofficial.great-site.net/)

To add new projects or update existing screenshots:
1. Save high-resolution PNG or WEBP screenshots (recommended 1280x800 or 1600x1000).
2. Save into this folder: `assets/images/projects/your-project-name.png`
3. Update the project card in `index.html`.
